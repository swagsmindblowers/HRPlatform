# BetterOff.FYI — Legal, privacy and governance (Workstream 7)

Each file in this folder is a **stub**, not a finished legal document. It states what the row in the scope of work requires, links to the code/feature it gates, and lists what a qualified professional needs to fill in. None of this has been reviewed by a lawyer, accountant, or the ICO, and none of it should be treated as legal advice — including advice to Claude's own operator.
